Masterly.Hash is a password-hashing library for .NET 8 and later. You call `Password.Hash` when a user sets a password and `Password.Verify` when they log in. The defaults follow RFC 9106, OWASP and NIST SP 800-63B: Argon2id with 64 MiB of memory and 3 passes, a 16-byte random salt, NFKC normalization, a 1024-byte input cap and a constant-time comparison.

Every hash you already have keeps working. Hashes from Masterly.Hash 1.x verify out of the box, and the `Masterly.Hash.Legacy` package adds bcrypt, ASP.NET Identity, Django, phpass, raw MD5 and SHA digests and external Argon2 hashes. When an old hash verifies, the result carries a fresh Argon2id replacement, so your table upgrades itself as users log in.

The core package targets `net8.0` and has no third-party dependencies: Argon2id is implemented inside the package. Seventeen optional packages add dependency injection, ASP.NET Core Identity, Entity Framework Core, remote peppers, password policy, tokens, blind indexes, integrity hashing, attack detection, analyzers, a command-line tool and test helpers. All 18 packages ship with the same version number.

## How it works

A stored password goes through four stages. You write code for the first and third; the library handles the second and tells you when the fourth is due. Select a stage to read its guide.
