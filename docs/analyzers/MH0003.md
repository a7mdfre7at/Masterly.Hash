# MH0003: Hard-coded pepper or key

| Property | Value |
|----------|-------|
| Category | Security |
| Default severity | Warning |
| Code fix | No |

## Cause

A compile-time constant is used where a secret key belongs:

- as key material passed to a `Masterly.Hash.Pepper.HmacPepper` constructor or to `HmacPepper.FromBase64`
  (including values inside an inline dictionary initializer), or
- assigned to, or used to initialize, a field, property or local named **pepper, hmacKey, secretKey, signingKey**,
  or returned from a property or method with such a name (`static byte[] Pepper => Convert.FromBase64String("...");`,
  `string GetSigningKey() { return "..."; }`).

"Constant" means a non-empty string literal or `const`, a `new byte[] { ... }` or collection expression of literals,
a `"..."u8` literal, or `Convert.FromBase64String` / `Convert.FromHexString` / `Encoding.X.GetBytes` applied to one
of those. A literal **fallback** counts as well: `Environment.GetEnvironmentVariable("PEPPER") ?? "dev-pepper"` and
`isDev ? "dev-key" : fromConfig` are reported, because a missing variable silently falls back to a key that ships in
the binary.

A zero-filled `new byte[32]` passed directly to `HmacPepper` is reported too: it is an all-zero key that is long enough
to pass the minimum key length check. A local named `pepper` created as `new byte[32]` is not reported, because it is
normally filled with `RandomNumberGenerator.Fill` next.

Key ids (`"k1"`) are not secrets and are ignored. So are names ending in metadata words (`pepperKeyId`,
`signingKeyName`, `secretKeyPath`), words that merely contain the pattern (`peppermint`), and empty strings.

## Why it matters

A pepper only helps if it is stored somewhere other than the database. A key compiled into the binary is visible in
source control, in build artifacts and to anyone who decompiles the application, and it cannot be rotated without a
release.

## How to fix

Load the key from a secret store, environment variable or protected configuration:

```csharp
// Before
var pepper = new HmacPepper("k1", Convert.FromBase64String("c2VjcmV0..."));

// After
var pepper = HmacPepper.FromBase64("k1", configuration.GetSection("Pepper:Keys").Get<Dictionary<string, string>>()!);
```

Or use one of the key-vault pepper packages (`Masterly.Hash.Pepper.AzureKeyVault`, `Masterly.Hash.Pepper.AwsKms`,
`Masterly.Hash.Pepper.HashiCorpVault`). Generate new keys with `HmacPepper.GenerateKey()`.

## When to suppress

Test fixtures that need a deterministic key. Prefer generating a key inside the test.
